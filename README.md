# AgriAssist India 🌾

AgriAssist is a digital agriculture assistant tailored for the Indian farming community. It helps farmers monitor their crop health, track seasonal sowing, and manage farm records effectively.

## 🚀 Features
- **AI Plant Disease Diagnosis:** Upload leaf images to detect common crop diseases and get organic treatment suggestions.
- **Seasonal Agri-Calendar:** Stay updated with Kharif, Rabi, and Zaid crop cycles.
- **Personal Dashboard:** Manage your farm activities and user account securely.
- **Data Protection:** Built with robust authentication and cloud-ready infrastructure.

## 🛠️ Built With
- **Frontend:** HTML5, Tailwind CSS
- **Backend:** Flask (Python)
- **Database:** SQLite (Development) / PostgreSQL (Production)
- **Deployment:** Render
- **AI Integration:** Hugging Face Inference API

## 📋 How to Run Locally
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`

## 🇮🇳 Vision
Supporting sustainable agriculture across India by providing accessible, data-driven farming tools to every farmer.
